# 验证范围

使用本机 PyTorch 2.10.0 对可选卷积进行了隔离测试，已验证：

- 零阶矩约束、网格缩放均关闭时，卷积输出及输入/参数梯度与普通 Conv2d 完全一致。
- 保持矩约束设置不变、关闭网格缩放时，新增缩放选项不改变输出和梯度。
- 零阶矩约束开启时，有效核零和，内部常数场响应为零，权重梯度正常。
- 自动间距、显式间距、域长度、缩放指数的数值行为正确。
- 自动模式拒绝不相等的横纵网格间距；拒绝非法间距、指数和域长度。
- 构造参数沿模型各层传递，两份主配置默认关闭两个选项。
- 同结构卷积参数可严格加载，所有 Python 文件语法检查通过。

已知一阶中心差分核在 16、32、64 网格上的最大误差分别约为 `6.50e-4`、`1.63e-4`、`4.07e-5`。这验证差分缩放实现，不证明训练后完整模型的收敛或稳定性。

完整模型前向、训练和跨分辨率实验尚未验证；当前可用 Python 环境缺少 timm。没有据此报告精度提升。

## 待处理事项

以下事项未在文档整理中改动：

1. McWilliams 训练脚本先划分数据，Dataset 内部再次截取子集；数据使用比例需在正式对比前核对。
2. 分布式训练日志损失按本地批次累计后除以完整数据集长度，统计值可能偏小。
3. 分布式恢复训练仅在 rank 0 加载已有 checkpoint，且不恢复完整训练状态；本阶段建议各组使用新 backbone 启动独立实验。
4. 推理设备和 checkpoint 轮次存在固定设置。
5. Forced Li 的模型配置声明空间尺寸为 128×128，而数据为 64×64；当前局部网格缩放使用实际张量尺寸，但其他依赖声明尺寸的代码需单独核对。
6. 部分基线配置存在重复或不完整条目，结构消融缺少部分模型实现。
7. 周期域的自动间距计算不改变卷积的零填充边界处理。

具体可选项和计算边界见 [模型文档](MODEL.md)。
